# Mission

## Right now, we are

Building the intelligence layer that makes every project in the factory carry a
durable understanding of itself — why it exists, its mission, decisions, risks,
and what matters now — and feeding that context into every agent handoff without
touching the proven workflow engine.

## Success looks like

- Every stage handoff carries `factory context + project context + task context`
  deterministically — current: yes (Phase 1) → target: yes, for every registered
  project (as of 2026-09-03)
- Judgement calls are classifiable against a machine decision protocol —
  current: yes (classifier) → target: wired into Chief of Staff intake (Phase 2)
- Proactive questions raised before a task blocks — current: no → target: five
  deterministic sensors running on a schedule (Phase 3)

## Explicitly not this quarter

- No UI work.
- No change to the 7-stage state machine or dispatch protocol.
- No model-assisted sensing until the deterministic sensors are proven.
