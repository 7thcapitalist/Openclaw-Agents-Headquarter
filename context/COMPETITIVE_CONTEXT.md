# Competitive context

## What users do today instead

- Single-agent coding assistants (Claude Code, Codex, Cursor) driven by hand, one
  task at a time, with the human holding all context and coordination.
- Generic multi-agent frameworks that orchestrate LLM calls but carry no durable
  company context, gates, or audit trail.
- Project management and note tools that hold context but do no work.

## Our wedge

A deterministic, auditable workflow engine with real gates (evidence,
independent review, human merge, signed high-risk approval) *plus* a per-project
intelligence layer that gives every agent the company's context and memory. Work
gets done and stays controllable and reviewable. The engine is boring on
purpose; the leverage is context + gates, not model cleverness.

## Not competing on

- Raw model capability — the harnesses are swappable.
- Being a hosted SaaS or a polished UI in V1.
- Fully autonomous production operations — human merge authority stays.
