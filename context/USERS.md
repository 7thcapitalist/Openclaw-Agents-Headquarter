# Users

## Primary user

The founder-operator: one person (or a very small team) running one or more
early-stage products, using OpenClaw as the company operating system. They set
direction, answer strategic decisions, and authorize merges. They do not want to
supervise agent logs.

## Jobs to be done

- Turn a natural-language goal into shipped, reviewed, audited software.
- See what is building, blocked, risky, or waiting on a decision — at a glance.
- Keep institutional memory so context is not lost between sessions or agents.

## Sensitivities

- Operator control and auditability are non-negotiable: every change is a
  reviewable PR, every completed stage leaves evidence, the founder merges.
- Privacy: private OpenClaw workspace state, credentials, sessions, and
  generated personal data must never enter this repo or a context pack.
- Consent: agents must not act outside declared scope on privacy, spend, public
  communication, or destructive operations without a founder decision.
