## Classification
- Project:
- Work type: ui | backend | architecture | bugfix | research | ops
- Risk: low | medium | high
- Preferred builder: codex | claude | cursor | auto

## Human decisions already made
List product choices the agents must treat as settled.

## Constraints
Privacy, compatibility, cost, deadline, architecture, or UX constraints.

## Verification expected
Tests, screenshots, logs, manual scenarios, performance checks, etc.

## Review routing
The reviewer MUST use a different model/harness from the primary builder unless there is no alternative.

## Escalation
Do not ask about ordinary reversible implementation choices. If a strategic decision is genuinely required, stop only the affected part of the task and return a Decision Card.
